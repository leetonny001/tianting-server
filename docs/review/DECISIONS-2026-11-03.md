## 3. 不需要你拍板、在 v0.2 里直接处理的

- **安全细节**：
  - "需要重新验证"不用 HTTP 401，避免被前端当成登录失效踢回登录页。
  - 新错误码按 ERRORS.md 的号段规则重新分配：errors.json 只增不改，写进去就改不了。
  - 运维接口的凭证改成每节点独立 + 请求签名 + TLS；不再用一把所有节点共用的静态 token。
  - pprof 和 Grafana 的访问控制。
  - 自动刷新不能让"空闲 30 分钟过期"失效。
- **可测性**：
  - 约 60 条有问题的验收标准，补齐输入、操作、预期结果，以及测试环境（例如双节点）。
  - 性能类验收标准改成能跑稳的统计口径：同一场景三次压测的 P99 就有 30ms、36ms、64ms 的波动。
- **告警阈值**和内存分析的口径对齐：存活内存和堆 + 栈不能拿来直接比较。
- **服务端补两项**：
  - 握手阶段被拒也要计入断开记录。
  - SDK 收到"被移出群"时保留会话的展示信息。
- **客户端补两项**：
  - 管理后台的新能力会带来新的客户端提示（被禁言、消息被删、封禁等），在 UI PRD 里补上，排进第二批。
  - PRD-core 第 5 节的 4 处调整（例如"退出登录"移到"我 → 设置"），正式列为 v1.3 变更。
