## 第一批

### FE-500 工程脚手架、路由、按权限的菜单与无权限页、无第三方资源
- 优先级：P0
- 批次：第一批
- 仓库：tianting-ops
- 依赖：CS-110（接口清单）
- AC：AC-OPS-02-2、AC-OPS-03-5
- 内容：
  1. Vite + React + TypeScript 工程、ESLint / Prettier、Vitest、Playwright、CI。
  2. 路由：总览（首页）、节点、指标、连接排查、配置检查、数据库与备份、审计日志、账号管理、个人设置；菜单按会话返回的权限点显示（`ops_viewer` 无"连接排查""审计日志""账号管理"）；直接输入无权限页面地址显示"无权限"页（权限判断以服务端 403 为准，菜单隐藏只是体验）。
  3. 不加载任何第三方资源（字体、图标、统计脚本全部打包进产物）；构建后扫描脚本（`scripts/scan-external.mjs`）：`<script src>`、`<link href>`、CSS `@import` / `url()`、代码中 `fetch` / `XMLHttpRequest` / `WebSocket` 的绝对地址（忽略 SVG `xmlns` 和注释），外部引用必须为 0；Playwright 走全部页面收集 CSP 违规报告，必须为 0。
- 估算：1 人日

### FE-501 API 客户端：错误码处理、CSRF、后台请求头、自动刷新与可见性
- 优先级：P0
- 批次：第一批
- 仓库：tianting-ops
- 依赖：FE-500
- AC：AC-OPS-01-16、AC-OPS-01-15、AC-OPS-01-5
- 内容：
  1. 按 PRD-admin 2.3 节处理错误码：4014 → 登录页（提示"登录已过期"）；4016 → 绑定二次验证页；4038 → TOTP 弹框后自动重放一次；4037 → 重新 `GET /console/api/session` 取令牌后重放一次；5031 → "审计服务不可用，操作未执行"；4290 / 4292 → 对应文案（4292 不自动重试）；其他按码显示文案，不展示 `msg`。
  2. 非 GET 请求带 `X-CSRF-Token`。
  3. 自动刷新 hook：总览、节点列表每 15 秒，可暂停；自动刷新请求带 `X-Console-Background: 1`，用户点击"刷新"和其他用户操作发起的请求**不带**；`visibilitychange` 为 hidden 时停止定时器，恢复可见时立即刷新一次。
  4. 每个数据卡片显示"数据时间"；`partial: true` 时页面顶部显示"节点 X 未响应，结果可能不完整"。
- 估算：1 人日
